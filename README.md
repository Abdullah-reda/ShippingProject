# Shipping Project

Shipping management system built with ASP.NET Core MVC + Web API.

## Architecture
- **Domains** - Entity models
- **DAL** - Data Access Layer (EF Core, Repository Pattern)
- **BL** - Business Logic Layer
- **UI** - ASP.NET Core MVC
- **WebApi** - REST API

## Tech Stack
- .NET / ASP.NET Core
- Entity Framework Core
- SQL Server

## Getting Started
1. Update the connection string in Shipping/appsettings.json
2. Run Update-Database in Package Manager Console
3. Run the Shipping project
